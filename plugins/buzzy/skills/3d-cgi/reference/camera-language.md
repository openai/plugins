# 3D CGI — Camera Movement

CG 运镜默认 **ease-in/out**，不要线性甩。写速度（°/s 或距离/s）和在 `VIDEO_DURATION` 里走完多少。
可以写 24fps cinematic *look*，不要承诺平台输出 60fps。

## Motions

1. **Slow orbital** — horizontal circle, ~45°/s, constant radius. Product turntable.
2. **Ascending crane** — up and back, parabolic. Scale reveal.
3. **Push-in / dolly forward** — toward subject; DOF can go wide → shallow.
4. **Tracking lateral** — slide L/R. Comparisons, tours.
5. **Reveal pan** — moderate yaw, A → B. Not a whip.
6. **Spiral ascent** — orbit + rise. Sci-fi / architecture.
7. **Glide-through** — through tunnel/corridor, environment streams past.
8. **Dolly zoom** — dolly vs zoom matched. Vertigo / psyche.
9. **Reverse crane** — back and up. Ending / context.
10. **Free / floating** — unconstrained 3D path, slow. Dream.
11. **Focus-shift hold** — almost static body, rack FG ↔ BG.
12. **Ease-in/out** — apply to every move unless stylized linear.
13. **Orbit at changing radius** — expand/contract spiral.
14. **Parallel track + depth** — lateral + dolly, parallax. Walkthrough.
15. **Static hold + internal motion** — locked camera, particles/transforms move.

Prefer **one continuous path**. 不要多段硬切。
