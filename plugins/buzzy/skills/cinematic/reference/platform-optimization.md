# Cinematic — Platform Optimization

只在用户**点名**平台时读。规格已冻结则不要用本节覆盖 `VIDEO_RATIO` / `VIDEO_DURATION`；只改钩子窗口、安全区、节奏建议。

参考图仍用 `<<<image_n>>>`，禁止 `@material`。

## TikTok（竖屏，钩子更狠）

- Hook window: 0–1s
- 建议画幅 9:16（用户已选定其它画幅则不改）
- 节奏偏快：4–6 ft/s，1–2s 一切
- 动作落在画面中心 70%（避开 UI）

```
Vertical 9:16 clip. Hook within 0.8s. Action occupies center 70% of frame.
Quick energy cuts every 1.5 seconds. Camera 4–6 ft/s. no background music
```

## YouTube Shorts

- Hook: 0–2s
- 16:9 或 9:16；两边都要能裁
- 节奏中快：3–4.5 ft/s
- 末帧可停 2s

```
Shorts-optimized cinematic clip. Hook at 0–2s establishing genre.
Pacing 3.5 ft/s. Compose so a 9:16 crop still holds the subject.
End frame holds 2 seconds. no background music
```

## Instagram Reels

- Hook: 0–1.5s
- 9:16 或 1:1
- 节奏中等：3–3.5 ft/s，先好看再快
- 调色要完整（teal-orange / golden hour）
- 动作落在中心 85%

```
Reels aesthetic. Hook within 1.5s with a visually stunning moment,
not dialogue-dependent. Sophisticated color grade. Smooth 3–3.5 ft/s.
Action within center 85%. no background music
```

## LinkedIn

- Hook: 0–2s
- 16:9
- 节奏慢：2–3 ft/s
- 专业、可听清的对白；不要娱乐向钩子
- 信任色：蓝 / 金 / 中性

```
LinkedIn professional clip. Hook within 2s establishing a leadership
or industry moment. Deliberate 2.5–3 ft/s. Clear enunciated voice-over
or dialogue. Trust-building color grade. no background music
```
