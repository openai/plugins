# Lots of Sounds Codex Plugin

Search, inspect, and add CC0 royalty-free sound effects to your projects via the Lots of Sounds CLI skill and hosted MCP server (`https://api.lotsofsounds.com/mcp`).

- Free tool (`browse_samples`) works without an API key.
- Full-catalog tools (`search_sounds`, `get_sound`, `download_sound`) require a Pro or Enterprise API key (`x-api-key` header) from https://www.lotsofsounds.com/dashboard/api-keys.
- Docs: https://www.lotsofsounds.com/docs/mcp
