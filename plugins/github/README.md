# GitHub

**Warning: this plugin is a public OAuth client.** Its OAuth client ID and
`client_secret` are intentionally distributed in [`.mcp.json`](.mcp.json).
Anyone can copy these values, so they cannot prove that a request comes from this
plugin. User access and refresh tokens must still be kept private.

For more context, see Okta's
[The Identity of OAuth Public Clients](https://developer.okta.com/blog/2022/06/01/oauth-public-client-identity).
