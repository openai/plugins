# Produce Helpers

These are implementation resources for the `produce` skill, not separately invocable skills.

- `ads/`: ad prompt-pack builder.
- `logos/`: logo review app and builder.
- `moodboards/`: the shared Creative Production board app and run builder.
- `offers/`: offer/product prompt-pack builder and packs.
- `shots/`: camera and crop route builder.
- `styles/`: style review app and builder.

Load a helper only after the corresponding `references/modes/*.md` route is relevant. User-facing routing stays in `intake` and `produce`.
