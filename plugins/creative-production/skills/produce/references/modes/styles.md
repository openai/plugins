# Styles

Use when the user wants reusable visual-system directions across image treatment, palette, typography, texture, lighting, and composition.

Vary treatment rather than inventing new product facts, claims, logos, chart data, or source evidence. Preserve the selected anchor when one exists.

Use the local review builder under `../../helpers/styles/` when the workflow needs a dedicated style comparison surface.

Show enough concrete visual evidence that the user can select a direction before final production.
