# Creative Production

Turn a brief, product, source image, selected concept, or rough idea into reviewable visual creative.

## When to use this plugin

Use Creative Production for campaigns, ads, social posts, product imagery, scenes, offers, logos, brand systems, styles, charts, decks, and related marketing or design assets.

If you invoke Creative Production without a concrete request, it opens a visual starting surface. Pick a starter and continue in natural language. When your request is concrete enough to generate safely, Creative Production opens the board first and builds into that same surface.

## Skills

| Skill | Use it for | Result |
| --- | --- | --- |
| `intake` | Starting without a brief, asking what Creative Production can do, or choosing a first direction | The Creative Production zero state with starter prompts |
| `produce` | Creating, exploring, adapting, refining, polishing, or reviewing visual creative | A reviewable board with generated work and follow-up iteration |

## Integrations

Creative Production can use available image-generation, Figma, and Canva capabilities while keeping the Creative Production board as the primary review surface.

You can start with a written brief, product image, reference asset, selected concept, or no brief at all.
